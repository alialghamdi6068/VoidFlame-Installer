# World archives

Upload a world as a ZIP archive, for example `duel-arena.zip`. The archive must contain `level.dat`, `region/`, etc. at the ZIP root, not inside an extra wrapper folder. Add a `world-zip` entry to `/manifest.yml` with `target: duel-arena`.

Existing world directories are never overwritten. Stop the server before installing or registering the world with Multiverse or another world manager.
